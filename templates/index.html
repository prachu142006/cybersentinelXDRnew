About Cyber Sentinel XDR

Cyber Sentinel XDR is a Flask-based cybersecurity monitoring platform inspired by enterprise SOC solutions. It detects multiple attack types, blocks malicious IP addresses, logs incidents, generates reports, and provides a professional dashboard for administrators.
